## 🚀 Quick Start

Para começar rápido, siga os passos:

**Resumo:**

Abra o Docker, e digite no terminal do VsCode:
```bash
docker compose up
```


1. Backend:
```bash
cd backend
npm install
npm run dev
```

2. Frontend:
```bash
cd frontend
npm install
npm run dev
```


Acesse: http://localhost:5173/Trabalho-1-fullstack/
