## 🚀 Quick Start

Para começar rápido, siga os passos:

**Resumo:**

1. Backend:
```bash
cd backend
npm install
npm run dev
```

2. Frontend:
```bash
cd frontend
npm install
npm run dev
```

Acesse: http://localhost:5173
